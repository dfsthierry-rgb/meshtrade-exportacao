# Central Mesh Export Desk

1. Import one or more MIRGOR purchase orders from the Overview screen.
2. Review every invoice line and complete the full English description, HS/NCM, quantity and unit value.
3. Complete the export parties and terms once in **Parties & settings**; then set invoice metadata and the USD/BRL reference rate.
4. In **Packing List**, add the packaging, gross/net weights, dimensions and dispatch notes supplied by Logistics.
5. Use **Export Excel** for the editable two-sheet workbook or **Official PDF** for the connected Commercial Invoice and Packing List.

The workspace is intentionally local to the browser. “Save draft” keeps the active draft on the current device; no order or commercial data is sent to a third party.
